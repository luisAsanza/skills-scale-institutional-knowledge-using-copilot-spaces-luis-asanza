# OctoAcme Role Onboarding Checklists

## Purpose
Provide standardized onboarding checklists for each role to ensure new team members quickly understand their responsibilities, key artifacts, communication channels, and integration points with other roles.

## How to Use
- Project Managers should assign the appropriate checklist to new team members during project initiation
- Team members should complete checklists within their first week on a project
- Use these checklists alongside the detailed role descriptions in [Roles and Personas](octoacme-roles-and-personas.md)

---

## Developer Onboarding Checklist

- [ ] Review [Roles and Personas](octoacme-roles-and-personas.md) - Developer section
- [ ] Access granted to code repositories and project board
- [ ] Local development environment setup completed
- [ ] CI/CD pipeline and testing framework understood
- [ ] Met with Project Manager for project overview and timeline
- [ ] Met with Product Manager to understand product vision and acceptance criteria
- [ ] Connected with DevOps Engineer for deployment process and monitoring
- [ ] Reviewed Definition of Done and coding standards
- [ ] Attended team standup and sprint planning
- [ ] Completed first PR and code review cycle

**Key Handoff Points:**
- Receive design specifications from UX Designer before implementing UI features
- Collaborate with Data Analyst/Data Scientist on instrumentation and tracking requirements
- Work with DevOps Engineer on deployment strategy and observability

---

## Product Manager Onboarding Checklist

- [ ] Review [Roles and Personas](octoacme-roles-and-personas.md) - Product Manager section
- [ ] Access granted to product analytics, roadmap tools, and project board
- [ ] Reviewed product vision, strategy, and current roadmap
- [ ] Met with stakeholders to understand business objectives
- [ ] Connected with Project Manager to understand delivery process and timeline
- [ ] Met with Customer Support/Advocacy Lead to review customer feedback and pain points
- [ ] Connected with Data Analyst/Data Scientist to define success metrics
- [ ] Reviewed existing user research with UX Designer
- [ ] Attended sprint planning and backlog refinement
- [ ] Reviewed and updated product documentation

**Key Handoff Points:**
- Define problem statements and success metrics with Data Analyst/Data Scientist
- Collaborate with UX Designer on feature requirements and user research
- Work with Project Manager on scope, timeline, and resource allocation

---

## Project Manager Onboarding Checklist

- [ ] Review [Roles and Personas](octoacme-roles-and-personas.md) - Project Manager section
- [ ] Access granted to project board, risk register, and communication channels
- [ ] Reviewed project charter and one-pager
- [ ] Met with Product Manager to understand product goals and priorities
- [ ] Connected with all core team members (Developers, UX Designer, DevOps, etc.)
- [ ] Reviewed current sprint status and backlog
- [ ] Understood escalation paths and stakeholder communication cadence
- [ ] Reviewed risk register and dependency tracking
- [ ] Scheduled regular syncs (standups, sprint planning, retrospectives)
- [ ] Reviewed project documentation standards and templates

**Key Handoff Points:**
- Coordinate with DevOps Engineer on deployment readiness and infrastructure risks
- Facilitate communication between Customer Support and Engineering on customer-impacting issues
- Track metrics and progress with Data Analyst/Data Scientist

---

## UX Designer Onboarding Checklist

- [ ] Review [Roles and Personas](octoacme-roles-and-personas.md) - UX Designer section
- [ ] Access granted to design tools (Figma, etc.) and design system
- [ ] Reviewed product vision and user personas with Product Manager
- [ ] Met with Customer Support/Advocacy Lead to review user feedback and pain points
- [ ] Connected with Developers to understand technical constraints and component library
- [ ] Reviewed existing user research and usability test results
- [ ] Understood design review process and critique schedule
- [ ] Reviewed accessibility standards and compliance requirements
- [ ] Met with Project Manager to understand sprint timeline and deliverables
- [ ] Completed first design handoff to Developers

**Key Handoff Points:**
- Provide design specifications and prototypes to Developers before implementation
- Collaborate with Product Manager on feature requirements and user research
- Gather user feedback from Customer Support/Advocacy Lead to inform design decisions

---

## Data Analyst / Data Scientist Onboarding Checklist

- [ ] Review [Roles and Personas](octoacme-roles-and-personas.md) - Data Analyst/Data Scientist section
- [ ] Access granted to data warehouse, analytics tools, and dashboards
- [ ] Reviewed data architecture and pipeline documentation with DevOps Engineer
- [ ] Met with Product Manager to understand success metrics and KPIs
- [ ] Connected with Developers to review instrumentation and tracking implementation
- [ ] Reviewed existing dashboards, reports, and experiments
- [ ] Understood data governance policies and security requirements
- [ ] Met with Project Manager to understand reporting cadence and metrics needs
- [ ] Set up development environment for SQL, Python, or R analysis
- [ ] Completed first metric definition or analysis

**Key Handoff Points:**
- Define success metrics with Product Manager at project initiation
- Work with Developers on tracking implementation and data quality
- Collaborate with DevOps Engineer on data pipeline reliability and monitoring

---

## DevOps Engineer Onboarding Checklist

- [ ] Review [Roles and Personas](octoacme-roles-and-personas.md) - DevOps Engineer section
- [ ] Access granted to cloud infrastructure, CI/CD tools, and monitoring systems
- [ ] Reviewed infrastructure architecture and IaC (Infrastructure as Code) setup
- [ ] Met with Developers to understand deployment requirements and pipeline
- [ ] Connected with Project Manager to understand release timeline and constraints
- [ ] Reviewed incident response procedures and on-call rotation
- [ ] Understood security and compliance requirements
- [ ] Connected with Data Analyst/Data Scientist to review data pipeline monitoring
- [ ] Reviewed observability stack (logging, metrics, tracing)
- [ ] Completed first deployment or infrastructure change

**Key Handoff Points:**
- Collaborate with Developers on CI/CD pipeline design and deployment strategy
- Report deployment readiness and infrastructure risks to Project Manager
- Provide incident status updates to Customer Support/Advocacy Lead

---

## Customer Support / Advocacy Lead Onboarding Checklist

- [ ] Review [Roles and Personas](octoacme-roles-and-personas.md) - Customer Support/Advocacy Lead section
- [ ] Access granted to support ticketing system, CRM, and knowledge base
- [ ] Reviewed product features and common customer workflows
- [ ] Met with Product Manager to understand product roadmap and priorities
- [ ] Connected with UX Designer to share user feedback and pain points
- [ ] Met with Developers to understand bug reporting and escalation process
- [ ] Connected with DevOps Engineer for incident response coordination
- [ ] Reviewed support metrics (CSAT, NPS, time to resolution)
- [ ] Met with Project Manager to understand release schedule and customer communications
- [ ] Completed first customer escalation or feedback synthesis

**Key Handoff Points:**
- Provide customer feedback to Product Manager and UX Designer regularly
- Report bugs and escalations to Developers with clear reproduction steps
- Coordinate with Project Manager on customer-impacting release communications
